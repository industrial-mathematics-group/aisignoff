## Summary

The new commit badges run on the default branch and the existing suite passes. The badge can overstate independent AI review in repositories using version-3 declarations and count a review level that lint rejects. The previous three issues in the unchanged diff and base-rule code still reproduce.

## Findings in this change

### Major — The commit badge counts a version-3 self-check as an independent review

[`src/aisignoff/changes.py:72`](../src/aisignoff/changes.py#L72), [command reference](../docs/commands.md#badge)

A repository with `version = 3` contains one declared commit with `AI-Review: A1` and a reviewer line identifying the generating session's self-check. The ordinary file badge correctly reports `A0 100%` on today's scale. `badge --commits` reports `A1 100%`. The badge always calls `parse_message` on the default scale. Old template boxes can be recognized by wording, but key-line declarations have no equivalent conversion in this command, even when the repository declares the scale.

The previous organisation workflow explicitly said historical trailers were counted as written and disclosed the mixed meanings in its job summary. The new command's documentation says it reads messages as the pre-merge check does, and its summary no longer gives that qualification. Readers can interpret A1 as independent review for content that only received a self-check. [Previous workflow](https://github.com/industrial-mathematics-group/.github/blob/2029331744dc070588cefcbf4a66ed20fad6bff5/.github/workflows/signoff-badges.yml#L8-L15)

Use the repository's known declaration scale where available. For a repository without configuration or with mixed historical trailer scales, document how the scale is determined or label the raw counts with their limitation.

### Minor — Conflicting review trailers can appear as a valid badge level

[`src/aisignoff/changes.py:72`](../src/aisignoff/changes.py#L72), [counted levels](../src/aisignoff/changes.py#L94)

A commit declares both `Human-Review: H0` and `Human-Review: H3`. Lint rejects the same declaration with exit 1. The commit badge exits 0, reports `H3 100%`, and emits no conflict warning. The parser attaches the conflict to the returned pieces, but the badge only checks their level strings and the separate flag for mixed trailers and checkboxes.

Use the parsed conflict information to mark the affected axis unknown or omit invalid declarations, and give a diagnostic. Add a conflicting-trailer case to the badge tests.
